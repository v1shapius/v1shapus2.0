# AK:END Judge Tool

Веб-инструмент для судей турниров по **Arknights: Endfield** в режиме "Сумрачный монумент" (Umbral Monument).

## Возможности

### Основные функции
- ✅ Настройка матча (Bo3, Bo5, групповой этап)
- ✅ Магазин матча с автоматическим расчетом монет и лимитов
- ✅ Генерация карт с контролируемым рандомом (система тегов и весов)
- ✅ Фаза защит и банов с полной логикой взаимодействия
- ✅ Сборка команд с учетом экстерминации и воскрешений
- ✅ Ввод результатов и автоматический подсчет очков
- ✅ Тай-брейк режим со специальными ограничениями
- ✅ Экспорт данных матча в JSON
- ✅ Чек-лист проверки экипировки

### Технические особенности
- Работает полностью в браузере (без сервера)
- Хранение данных в localStorage
- Экспорт результатов для дальнейшего анализа
- Адаптивный дизайн для трансляции экрана
- Темная тема с неоновыми акцентами

## Установка и запуск

### Вариант 1: GitHub Pages (рекомендуется)
1. Загрузите файлы репозитория на GitHub
2. Включите GitHub Pages в настройках репозитория
3. Откройте сайт через браузер

### Вариант 2: Локальный запуск
1. Откройте `index.html` в любом современном браузере
2. Для корректной загрузки JSON может потребоваться локальный сервер:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js (если установлен http-server)
   npx http-server
   ```

## Использование

### 1. Настройка матча
- Введите Discord-теги игроков
- Выберите формат матча (Group/Bo3/Bo5)
- Нажмите "Start Match"

### 2. Магазин
- Каждый игрок покупает ресурсы на стартовые монеты
- Free 4★ воскрешения без ограничений
- Лимиты покупок зависят от формата

### 3. Генерация карт
- Нажмите "Generate Maps" для случайного набора
- Система контролирует веса тегов (сумма ≤ 1.0)
- Подтвердите карты для перехода к банам

### 4. Баны и защиты
- **Фаза защит**: игроки применяют купленные защиты
- **Фаза банов**: поочередные или одновременные баны
- Защита требует 2 банов для снятия
- Само-бан снимает защиту без бана для себя

### 5. Сборка команд
- Выберите 1-4 персонажей на карту
- Система отслеживает использованных персонажей
- Требуется воскрешение для повторного использования
- Отметьте чек-боксы проверки экипировки

### 6. Проведение
- Введите время прохождения обоих игроков
- Разница ≤ 3 секунд = ничья
- Рестарты доступны до завершения оппонентом

### 7. Результаты
- Автоматический подсчет очков
- При ничьей в матче — тай-брейк
- Экспорт данных в JSON

## Форматы данных

### Персонажи (characters.json)
```json
{
  "id": "c_001",
  "name": "Antal",
  "rarity": 6,
  "role": "Guard",
  "faction": "Rhodes Island",
  "icon": "/assets/characters/antal.png"
}
```

```json
    { "name": "DefenseHeavy", "weight": 0.3 }

  "hasBoss": true
}
```

## Правила турнира

Инструмент реализует правила турнира **AK:END — BEANDUSTRIAL CHUBBIES «Extermination» Сезон 1**:

- Экстерминация: 1 персонаж = 1 карта (без воскрешения)
- Бесплатные воскрешения только для 4★
- Баны взаимные для обоих игроков
- Ничья при разнице ≤ 3 секунд
- Тай-брейк: без 6★, banned Da Pan и Avivenna
